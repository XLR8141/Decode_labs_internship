# Project 1: Rule-Based Logic

The first project focuses on the IPO model to create a deterministic system. The goal is to build a white box program where every output is directly traceable to a specific logic gate. 
The software functions by taking a raw feed of user input and passing it through a sanitization and normalization process. This removes variations in casing and spacing to ensure the logic 
skeleton can match intents accurately. By using explicit if-else instructions within a continuous digital loop, the chatbot provides a controlled interface with zero risk of hallucination. 
This architecture is essential for creating high-clarity systems where programmatic decision-making must remain transparent and predictable.
