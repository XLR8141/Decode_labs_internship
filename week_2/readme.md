# Project 2: Predictive Data Classification

The second project transitions from manual rules to supervised learning and predictive modeling. This milestone establishes a digital foundation for teaching a machine to 
recognize patterns in numerical data and categorize information with precision. A core requirement is the gatekeeper rule of scaling, which uses standard normalization to 
ensure that different features contribute equally to the algorithm without being biased by their raw magnitudes. The data is divided into a training set for pattern recognition 
and a test set for validation. By applying the K-Nearest Neighbors algorithm, the system learns to classify new entries based on their mathematical proximity to existing data points 
within a balanced feature space.
